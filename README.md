## Topic Overview

### What is Prompt Sensitivity?

Prompt sensitivity refers to the tendency of a Large Language Model (LLM)
to produce different outputs when the wording, structure, formatting,
ordering, or other characteristics of a prompt are changed, even when the
underlying meaning of the prompt remains similar.

For example, two prompts may ask the same research question using different
wording. An LLM may produce different explanations, evidence, reasoning
paths, or conclusions for the two prompts.

### Why is Prompt Sensitivity Important?

Prompt sensitivity is important because LLMs are increasingly being used for
research assistance, information synthesis, scientific writing, question
answering, and reasoning.

If small changes in a prompt produce substantially different conclusions,
then researchers may have difficulty determining whether an LLM-generated
conclusion is stable and reliable.

This creates an important research problem:

> **How stable are LLM-generated research conclusions when the same research
> question is expressed using different prompts?**

### Key Factors

Prompt sensitivity can be influenced by:

- Prompt wording
- Prompt structure
- Prompt formatting
- Few-shot example selection
- Few-shot example ordering
- Instruction placement
- Role or persona instructions
- Context provided to the model
- Question formulation
- Sampling and decoding settings
- Model architecture and model version
- Evaluation methodology

### Research Objective

The main objective of this research topic is to understand how changes in
prompt formulation affect the consistency and stability of conclusions
generated by Large Language Models.

The research also investigates methods for measuring prompt sensitivity,
improving robustness, and evaluating whether an LLM-generated conclusion
remains consistent under semantically equivalent prompts.

## Research Challenges

Several challenges remain when studying prompt sensitivity.

### 1. Measuring Sensitivity

There is no single universal measure of prompt sensitivity. Different
studies may use different metrics and experimental designs.

### 2. Separating Prompt Effects from Model Effects

Changes in output may result from prompt variations, model differences,
sampling randomness, or other experimental factors.

### 3. Semantic Equivalence

Two prompts can have different wording while expressing the same meaning.
Determining whether two prompts are truly semantically equivalent is itself
a challenging problem.

### 4. Reproducibility

LLM outputs can vary depending on model versions, API settings, sampling
parameters, and system configurations.

### 5. Evaluation Bias

The evaluation method itself may introduce artifacts that make a model
appear more or less sensitive than it actually is.

### 6. Research Conclusion Stability

A major challenge is determining whether different model outputs represent
meaningful differences in conclusions or simply variations in wording and
presentation.

## Research Gaps

Important research gaps include:

1. Developing standardized prompt-sensitivity benchmarks.
2. Developing better metrics for measuring conclusion stability.
3. Studying prompt sensitivity across different LLM families.
4. Investigating sensitivity in scientific and research-oriented tasks.
5. Studying whether prompt sensitivity changes with model scale.
6. Separating semantic changes from superficial prompt changes.
7. Developing methods for automatically detecting unstable conclusions.
8. Studying the effect of prompt sensitivity on AI-assisted academic
   research.
9. Developing reproducible protocols for prompt-sensitivity experiments.
10. Investigating how multiple equivalent prompts can be used to estimate
    confidence in an LLM-generated conclusion.
